# 后端缺口清单

这份清单用于记录已完成前端页面中，暂时仍需要后端接口、数据库或真实业务流程支持的部分。每完成一个界面就追加对应条目，后续统一补齐并逐项验收。

## 后端清单审计（2026-09-05）

- 当前清单共有 50 项未完成项、15 项已确认完成项；未完成项主要来自账号与隐私、画像与推荐、课程规划、岗位数据、学习记录、设置持久化和知识库治理。
- 当前 API 已具备认证、画像、偏好、对话、反馈、知识库、专业目录、推荐、培养方案和岗位详情等基础端点；`/api/health` 当前可正常返回。
- 当前后端仍以 MVP 为主：部分业务数据来自内存常量或前端状态，JSON 偏好缺少 schema，课程与岗位缺少真实时序/业务状态，账号关系和权限模型尚未建立。
- 审计发现 Docker Compose 没有显式传入 `MOCK_LLM=true`，而配置默认值为 `false`，存在误启用真实模型的风险；本阶段已改为 Compose 显式传入且配置默认使用 mock。
- 本轮已先完成 P0 中的 mock 运行时固定、密码策略统一和改密后 token 轮换，并新增无外部服务依赖的后端契约测试；随后开始 P1 账号数据持久化。

### 建议实施顺序

1. **P0：运行与安全底座**——固定 mock 配置；统一密码策略并轮换旧 token；补充输入校验、管理员权限、文件上传限制、数据删除和关键操作审计；将数据库初始化从 `create_all` 逐步收敛到迁移流程。
2. **P1：账号数据与核心业务持久化**——结构化画像/偏好 schema、引导完成状态、头像、联系方式、岗位收藏、学习记录、隐私设置、目标培养方案和冲突策略。
3. **P1：推荐与课程规划真实化**——将评分规则和先修要求配置化，补充课程开设学期/时间/校区/容量，生成并保存可追溯的推荐报告和培养方案。
4. **P2：职业与同步服务**——岗位来源更新、岗位详情扩展、投递状态、数据同步任务、缓存清理、通知任务和反馈工单。
5. **P2：知识库与伴学增强**——文档版本有效期、上传存储、检索质量评估、知识图谱数据库化、知识点学习记录和上下文问答。

### 审计边界

- 审计阶段核对了仓库代码、迁移文件、前端 API 调用、OpenAPI 路由和本地健康检查；随后已按审计结论先落地 P0 的 mock 与认证安全修复。
- 当前本地后端自测脚本未能通过系统 Python 启动器执行，原因是本机 Python 启动路径编码异常；CI 仍配置为执行 `scripts/verify_core.py`，后端正式改动前需要在 Docker 或 CI 环境补跑完整验证。

## 记录规则

- 前端页面可以先完成展示和交互占位，但不得把占位数据误认为真实业务数据。
- 后续后端阶段按页面逐项实现接口、持久化、权限校验和异常状态，再回填前端并验收。
